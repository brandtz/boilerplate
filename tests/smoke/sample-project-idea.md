# Sample Project Idea: Task Tracker API

## What is this project?
A minimal REST API for managing tasks (to-do items). Users can create, read, update, and delete tasks. Each task has a title, description, status (pending/in-progress/done), and due date.

## Who is the sponsor?
Single developer acting as all human roles.

## Tech stack preferences
- **Language:** TypeScript
- **Framework:** Express.js
- **Database:** SQLite (local file, no external service)
- **Deployment:** Local only (no cloud deployment)
- **Testing:** Jest

## External dependencies
None — this is a self-contained local API with no third-party integrations.

## Team composition
One person — the sponsor is the sole human with full authority over all decisions.

## Available tools and environment
- VS Code with GitHub Copilot
- Node.js 20+
- Git
- No MCP servers
- No Docker

## Known constraints
- No authentication required (local-only tool)
- No frontend (API only)
- Must work offline

## What does success look like?
A working API with CRUD endpoints, test coverage above 80%, and clean documentation.
