# Prompt: Environment and Secrets Standard

## Sequence Position
9.0.1 — Seventh implementation prompt (Rec 7)

## Phase
Implementation

## Objective
Create an environment and secrets management standard that prevents agents from hardcoding secrets, ensures `.env.example` files are generated, and establishes review checkpoints for secret leaks.

## Dependencies
- 8.0.1 (integrations map) — integrations.md documents env vars per service

## Prerequisites
- Prompt 8.0.1 complete

## Context for the Agent
There is no standard for how agents handle environment variables, secrets, API keys, or deployment configuration. Agents may hardcode values, commit secrets, or make assumptions about runtime environments. This is a critical gap for production SaaS. The integrations map (Rec 5) documents which env vars each service needs; this standard governs how they are managed.

## Scope

### E1-S7-T1: Create `agents/standards/environment-secrets-standard.md`
Standard must define:
- All secrets MUST be referenced via environment variables, never hardcoded
- `.env.example` MUST exist documenting every required variable (with placeholder values, never real secrets)
- `.env` files MUST be in `.gitignore` — validate this during project setup
- The DevSecOps role MUST review every implementation handoff for secret leaks
- Deployment configuration MUST be documented in `integrations.md`
- Local development setup MUST be reproducible from `.env.example` alone
- The close-out checklist gains a "secrets audit" step

### E1-S7-T2: Update bootstrap prompt (00)
Add instructions to generate `.env.example` during initial project scaffolding.
Add `.env` to the `.gitignore` template if not already present.

### E1-S7-T3: Update DevSecOps role
Add mandatory secrets review responsibility to the DevSecOps role file (`agents/roles/security/devsecops-engineer.md`):
- Review every implementation handoff for hardcoded secrets
- Validate `.gitignore` excludes `.env` files
- Reference the environment-secrets standard as required reading

### Post-implementation
Run `scripts/validate-boilerplate.sh` — must pass.
