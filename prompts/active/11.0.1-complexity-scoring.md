# Prompt: Complexity Scoring in Prompts

## Sequence Position
11.0.1 — Ninth implementation prompt (Rec 6, final implementation)

## Phase
Implementation

## Objective
Add a `complexity` field (S/M/L/XL) to the prompt template and update the prompt-builder standard to enforce complexity scoring during prompt generation. No token budgets, no auto-splitting — just visibility.

## Dependencies
- 10.0.1 (team mapping) complete — all context layer work is done

## Prerequisites
- Prompt 10.0.1 complete

## Context for the Agent
Prompts have no complexity estimate. The dashboard tracks completion status but cannot predict how much work remains or flag prompts that are too large for a single agent session. Adding a simple S/M/L/XL score provides visibility without the overhead of token budget estimation.

**Simplified scope per sponsor decision:** Complexity score only. No token budgets. No auto-splitting. No max-files-touched rule.

## Scope

### E1-S6-T1: Update `agents/templates/prompt-template.md`
Add a `complexity` field to the frontmatter section:
```yaml
complexity: "M"  # S = small (1-2 files), M = medium (3-5 files), L = large (6-8 files), XL = extra-large (9+ files or cross-layer)
```

### E1-S6-T2: Update `agents/standards/prompt-builder-standard.md`
Add a "Complexity Scoring" section:
- Every generated prompt MUST include a complexity score in frontmatter
- Scoring guide:
  - **S** — 1–2 files touched, single-layer, straightforward
  - **M** — 3–5 files touched, may span 2 layers, moderate decisions
  - **L** — 6–8 files touched, cross-layer, significant decisions
  - **XL** — 9+ files or fundamental cross-cutting changes
- The Standards Guardian flags prompts without complexity scores
- XL prompts should include a note about splitting consideration (advisory, not mandatory)

### E1-S6-T3: Backfill complexity scores on upgrade prompts
Add `complexity` to the frontmatter of all 9 prompts in this project (3.0.1–11.0.1) if not already present. Use the scoring guide to assign appropriate values.

Run `scripts/validate-boilerplate.sh` — must pass.
