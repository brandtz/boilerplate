# Prompt: AGENTS.md and Copilot Instructions

## Sequence Position
5.0.1 — Third implementation prompt (Rec 2)

## Phase
Implementation

## Objective
Create `AGENTS.md` at the repo root and `.github/copilot-instructions.md` so that GitHub Copilot agents are primed with repo-level behavioral context when starting any session. Create a template for `AGENTS.md` so new projects can generate their own.

## Dependencies
- 4.0.1 (conventions layer) — conventions file must exist for AGENTS.md to reference

## Prerequisites
- Prompt 4.0.1 complete

## Context for the Agent
GitHub Copilot reads `.github/copilot-instructions.md` automatically when present. `AGENTS.md` is a human-readable and agent-readable summary of how the repo's agent system works. Together they provide session priming without requiring the agent to read the full standards chain. No separate standard document is needed — the two files are self-documenting.

- `agents/context/project-charter.md`
- `agents/context/conventions.md`

- `agents/standards/handoff-standard.md`
- `docs/boilerplate-upgrade-intake.md` — Recommendation 2 details

## Scope

### E1-S2-T1: Create `AGENTS.md` at repo root
Content should include:
- What this repo is (agentic SaaS team factory boilerplate)
- How the agent system works (roles, prompts, handoffs, standards)
- Current project name and status (read from `agents/context/status-dashboard.md`)
- Key file locations (agents/, prompts/, dashboard/, docs/)
- Role index (list of roles with file paths)
- Quick-start instructions for new agent sessions

### E1-S2-T2: Create `.github/copilot-instructions.md`
Content should include:
- Repo-wide behavioral rules for Copilot agents
- Always read the current prompt's required reading before acting
- Follow the prompt lifecycle standard for close-out
- Follow the handoff standard for session handoffs
- Reference `agents/context/conventions.md` for coding patterns
- Reference `agents/context/project-charter.md` for project scope
- Do not modify files outside the prompt's stated scope

### E1-S2-T3: Create `agents/templates/agents-md-template.md`
A template version of AGENTS.md with placeholder sections so new projects can generate their own.
