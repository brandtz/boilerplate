# Prompt: Stack Conventions Context Layer

## Sequence Position
4.0.1 — Second implementation prompt (Rec 1)

## Phase
Implementation

## Objective
Create the stack conventions context file and template so that every project captures its tech stack, framework conventions, naming patterns, and deployment targets during intake. Update the intake prompt and required-reading chain to integrate conventions.

## Dependencies
- 3.0.1 (self-test script) — must pass before and after this work

## Prerequisites
- Prompt 3.0.1 complete

## Context for the Agent
The boilerplate is stack-agnostic by design. But real projects need a place to record stack-specific decisions (frameworks, database choices, deployment targets, coding patterns) so that every downstream prompt respects them. This prompt creates that mechanism.

## Required Reading
- `agents/context/project-charter.md`
- `agents/standards/prompt-lifecycle-standard.md`
- `agents/standards/handoff-standard.md`
- `docs/boilerplate-upgrade-intake.md` — Recommendation 1 details and acceptance criteria

## Scope

### E1-S1-T1: Create `agents/templates/conventions-template.md`
A template with sections for:
- Tech Stack (language, framework, runtime, versions)
- Database and Storage (provider, ORM, migration tool)
- Deployment (target platform, build output, CI/CD)
- Coding Conventions (naming, file structure, import ordering)
- Testing Conventions (framework, coverage expectations, test file location)
- Design System (component library, styling approach)
- API Conventions (REST/GraphQL, auth pattern, error format)

Each section should have placeholder guidance in HTML comments.

### E1-S1-T2: Create `agents/context/conventions.md`
Copy from the template with the boilerplate instruction:
> This file is populated during project intake. Conventions are validated during architecture review.

### E1-S1-T3: Update intake prompt (01)
Add a conventions interview section to `prompts/active/01_MASTER_AGENT_PROJECT_INTAKE_PROMPT.md`:
- Ask the sponsor about their tech stack, deployment target, coding patterns
- Populate `agents/context/conventions.md` from the answers

### E1-S1-T4: Update required-reading references
- If `agents/standards/required-reading-standard.md` exists, add `conventions.md` to the universal tier
- Add `conventions.md` to the required reading list in the prompt-builder standard so implementation prompts include it

### Post-implementation
Run `scripts/validate-boilerplate.sh` — must pass with new files in place.

## Constraints
- The conventions file must be a template, not pre-filled with any specific stack
- Do not modify the dashboard code
- Keep the template under 60 lines
